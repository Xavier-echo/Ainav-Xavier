# AI 文档编写学习导航 - 产品需求文档

## 1. 产品概述

### 1.1 产品定位
面向零基础用户的 AI 文档编写学习导航平台，帮助用户掌握如何用 Markdown 文档清晰表达需求，让 AI 更好地理解并执行任务。效仿"鱼皮编程导航"的资源聚合模式，提供结构化、分类清晰的学习资源导航。

### 1.2 目标用户
- 刚接触 AI 工具的初学者
- 想提升与 AI 协作效率的开发者/产品经理
- 需要编写需求文档、技术文档的职场人士
- 对 Markdown 语法不熟悉的新手

### 1.3 核心价值
- **零基础友好**：从最基础的 Markdown 语法讲起
- **实战导向**：每个分类都配有实际案例和模板
- **资源聚合**：精选优质教程、工具、模板，避免信息过载
- **学习路径清晰**：按难度和主题组织，循序渐进

## 2. 功能需求

### 2.1 首页
- **Hero 区域**：产品 slogan + 搜索框
- **数据统计**：资源总数、分类数、用户数（模拟）
- **精选推荐**：展示 4-6 个精选资源卡片
- **分类导航**：网格展示所有分类卡片
- **学习路径**：推荐学习顺序

### 2.2 分类导航页
- 展示所有分类卡片（网格布局）
- 每个分类显示：图标、名称、描述、资源数量
- 支持按难度筛选（入门/进阶/高级）
- 点击分类进入详情页

### 2.3 分类详情页
- 分类头部信息（图标、名称、描述）
- 该分类下的所有资源列表
- 资源卡片包含：标题、描述、难度标签、标签、链接
- 面包屑导航

### 2.4 资源详情页
- 资源完整信息展示
- 难度标识、分类标识、精选标识
- 标签展示
- 外部链接按钮
- 相关推荐资源

### 2.5 精选推荐页
- 展示所有标记为精选的资源
- 区分精选资源和普通资源

### 2.6 搜索功能
- 全局搜索框（导航栏 + Hero 区域）
- 实时搜索结果展示
- 支持按标题、描述、标签搜索
- 无结果时显示友好提示

## 4. 设计规范

### 4.1 视觉风格
- **主题**：深色模式（Dark Mode）
- **主色调**：黑色背景 + 琥珀色/橙色强调色
- **辅助色**：白色文字 + 灰色次要文字
- **风格**：现代、简洁、专业，效仿鱼皮导航的卡片式设计

### 4.2 交互设计
- 卡片悬停效果（上浮 + 阴影 + 边框高亮）
- 平滑过渡动画
- 响应式布局（移动端友好）
- 搜索实时反馈

### 4.3 字体
- 中文：Noto Sans SC
- 英文：系统默认无衬线字体

## 5. 非功能需求

### 5.1 性能
- 首屏加载时间 < 2s
- 路由切换流畅无卡顿
- 搜索响应时间 < 100ms

### 5.2 可访问性
- 支持键盘导航
- 足够的颜色对比度
- 语义化 HTML 结构

### 5.3 技术栈
- React 18 + TypeScript
- Vite 6（构建工具）
- TailwindCSS 3（样式）
- React Router DOM（路由）
- Lucide React（图标）

## 6. 页面路由

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | Hero + 精选 + 分类 |
| `/categories` | 分类导航 | 所有分类网格展示 |
| `/category/:id` | 分类详情 | 某分类下的资源列表 |
| `/featured` | 精选推荐 | 所有精选资源 |
| `/resource/:id` | 资源详情 | 单个资源的完整信息 |

## 7. 数据模型

### 7.1 资源（Resource）
```typescript
interface Resource {
  id: string;              // 唯一标识
  title: string;           // 标题
  description: string;     // 描述
  url: string;             // 外部链接
  category: string;        // 分类 ID
  tags: string[];          // 标签数组
  difficulty: '入门' | '进阶' | '高级';  // 难度
  icon: string;            // 图标名称
  isFeatured?: boolean;    // 是否精选
}
```

### 7.2 分类（Category）
```typescript
interface Category {
  id: string;              // 唯一标识
  name: string;            // 分类名称
  description: string;     // 分类描述
  icon: string;            // 图标名称
  color: string;           // 主题色
  resourceCount: number;   // 资源数量
}
```
